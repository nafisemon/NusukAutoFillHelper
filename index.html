কোডের উৎস ও সতর্কতা
প্রধান তালিকা Umrah Codes-এর প্রকাশ্য API থেকে আসে। API প্রকাশকের বর্ণনা অনুযায়ী কোডগুলো ব্যবহারকারী ও অন্যান্য উন্মুক্ত কমিউনিটি উদ্যোগ থেকে সংগৃহীত; এটি Nusuk-এর সরকারি তালিকা নয়। কোড সচল বা Key দেবে—নিশ্চয়তা নেই। ব্যক্তিগত/বন্ধ গ্রুপ থেকে অনুমতি ছাড়া তথ্য নেওয়া হয় না।
