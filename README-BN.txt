Nusuk Key Collector — Shahriar Nafis Edition

This package prominently displays SHAHRIAR NAFIS in the app.

To update the existing GitHub Pages app:
1. Extract this ZIP.
2. Upload the files to the repository root, replacing files with the same names.
3. Commit the changes.
4. Wait for GitHub Pages to publish the update.
5. Refresh the app. If the old version remains, close the installed PWA and clear that site's cache.

The code list is fetched from the documented community JSON endpoint:
https://umrahcodes.click/open-data/v1/codes.json

The API's developer page says it permits browser CORS requests and asks users to cache downloads for at least 15 minutes. Codes are community-submitted and are not guaranteed to work in Nusuk. This is not an official Nusuk app and does not auto-submit or verify codes.
